# Hi, I'm Edward

I build tools around AI agents, plus web apps, a browser game, and the odd hardware project.
I write at [keeploop.dev](https://keeploop.dev).

## Projects

### AI tools and agents

- 🏋️ **[Repfloor](https://repfloor.dev)** · TypeScript, Cloudflare Workers, React

  A gym for AI engineering skills. Follow the AI engineering roadmap, then practise each topic with drills that come back on a spaced-repetition schedule.

- 🌳 **[Cambrian Tree Orchestrator](https://github.com/edward-sia/cto)** · TypeScript

  AI agents debate how to build your task, and each disagreement becomes its own branch. Codex implements the best branches, and CTO ranks the results against your checks.

- 📊 **[LLM Usage Bar](https://github.com/edward-sia/llm-usage-tracker)** · Swift

  A macOS menu bar app that shows your Claude and ChatGPT usage limits and your OpenRouter balance at a glance.

- 🧹 **[AI Slop Detector](https://github.com/edward-sia/ai-slop)** · JavaScript

  A Chrome extension that flags filler text on any page with a local Ollama model. Nothing leaves your machine.

- 🔍 **[Claude PR reviewer](https://github.com/edward-sia/.github)** · Shell, GitHub Actions

  One `@claude` code reviewer shared by all my repos. Edit the rubric once and every repo picks it up.

- 🛒 **MCP merchant generator** · TypeScript

  An MCP server that generates test merchants and scores how ready each one is for AI agents to check out through the ACP and UCP protocols.

- 🤝 **Multi-agent pattern kits** · TypeScript · [OpenAI version](https://github.com/edward-sia/2-agent-chat) · [Claude version](https://github.com/edward-sia/2-agent-chat-claude)

  Two learning repos showing the main ways one agent can call others, each pattern explained with an everyday analogy.

### Automation

- 🏠 **[rent-workers](https://github.com/edward-sia/rent-workers)** · TypeScript, Cloudflare Workers

  Creates monthly rent charges in Airtable and tracks tenant payments through a Telegram bot.

### Games

### Hardware

- 🚪 **[D5-Evo BLE gate trigger](https://github.com/edward-sia/d5-evo-gate)** · C++, Kotlin, Swift
